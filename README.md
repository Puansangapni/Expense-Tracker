# 💰 Personal Expense Tracker

A web-based personal expense tracker built with Django that allows users to manage their income and expenses in one place.

## 📌 About the Project

Personal Expense Tracker is a web application developed to help users record, manage, and monitor their personal financial transactions.

The application provides a dashboard that displays financial summaries and transaction data, making it easier for users to track their income and expenses.

This project was developed as a portfolio project to demonstrate web development skills using Django.

## ✨ Features

- User registration and login
- User authentication
- Dashboard
- Add income and expense transactions
- Edit transactions
- Delete transactions
- Transaction categories
- Income and expense management
- Transaction date
- Transaction description
- Transaction filtering
- Financial summary
- Expense charts
- CSV export

## 🛠️ Tech Stack

- **Python**
- **Django**
- **SQLite**
- **Bootstrap 5**
- **Chart.js**
- **Git & GitHub**
